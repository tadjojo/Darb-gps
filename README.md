# DARB GPS Web — Alpha 1.0

واجهة ويب عربية متجاوبة لمنصة دَرْب GPS، مضافة إلى المستودع بجانب تطبيق Flutter والخادم NestJS دون استبدالهما.

## التشغيل محلياً

لا تحتاج الواجهة إلى Node.js أو عملية build. افتح `index.html` عبر خادم ملفات محلي، مثلاً:

```bash
cd web
python -m http.server 8081
```

ثم افتح `http://localhost:8081`.

## النشر على GitHub Pages

1. ارفع كامل المستودع إلى GitHub.
2. افتح **Settings → Pages**.
3. ضمن **Build and deployment** اختر **GitHub Actions**.
4. شغّل workflow المسمى **Deploy DARB GPS Web to GitHub Pages** من تبويب Actions، أو ادفع تحديثاً يغيّر ملفات `web/`.
5. سيظهر رابط الموقع في Settings → Pages بعد نجاح النشر.

الـ workflow الموجود في `.github/workflows/deploy-web-pages.yml` ينشر محتويات مجلد `web/` فقط.

## ربط API

من صفحة **الإعدادات والربط** أدخل:

- عنوان API الأساسي، شاملاً `/api/v1`، مثال: `https://api.example.com/api/v1`.
- معرّف المؤسسة UUID الذي أُنشئ مسبقاً على الخادم.

ثم احفظ الإعدادات واختبر الاتصال وسجّل الدخول بحساب مهيأ مسبقاً. تسجيل الدخول يستخدم `POST /auth/login`، وجلب المركبات يستخدم `GET /organizations/:organizationId/vehicles`، والإضافة تستخدم `POST /organizations/:organizationId/vehicles` وفق واجهات الخادم الحالية.

**تنبيه أمني وتشغيلي:**
- GitHub Pages يستضيف ملفات الواجهة الثابتة فقط، ولا يشغّل NestJS أو PostgreSQL أو Redis.
- يجب نشر الخادم وقاعدة البيانات بشكل منفصل، وتفعيل HTTPS وضبط `CORS_ORIGINS` على نطاق الموقع المنشور.
- لا تضع أسرار الخادم أو مفاتيح خاصة أو كلمات مرور داخل ملفات الواجهة أو GitHub.
- رموز الجلسة تحفظ في `sessionStorage` لهذه النسخة التجريبية؛ قبل الاستخدام التجاري/الإنتاجي يلزم مراجعة أمنية، ويفضّل اعتماد جلسات آمنة عبر BFF وملفات HttpOnly/Secure/SameSite.
- بيانات المركبات الافتراضية أمثلة واجهة وليست بيانات حقيقية. لا تعرض هذه النسخة كخدمة تتبع إنتاجية.
- الخادم الحالي لا يوفّر بعد كل واجهات التنبيهات والتقارير والملاحة المطلوبة؛ تظهر تلك الأقسام كواجهات تمهيدية.

## ما تحتويه النسخة

- لوحة مؤشرات للمركبات وحالاتها.
- خريطة OpenStreetMap عبر Leaflet مع علامات توضيحية.
- عرض المركبات والبحث فيها.
- تسجيل الدخول وربط API وإدارة المركبات الأساسية عند تهيئة الحساب والمؤسسة.
- صفحات تمهيدية للأجهزة والرحلات والتنبيهات والتقارير.
- تصميم RTL متجاوب للشاشات الكبيرة والهواتف.
