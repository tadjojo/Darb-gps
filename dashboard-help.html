دَرْب GPS — دليل الإعداد والربط

هذه لوحة تجريبية للملاحة وتتبع المركبات. في وضع العرض التجريبي، البيانات المعروضة أمثلة ولا تمثل مركبات حقيقية.

ربط API

  1. افتح من القائمة الجانبية الإعدادات والربط.
  2. أدخل عنوان API المنشور مع المسار /api/v1.
  3. أدخل معرّف المؤسسة بعد إنشائها أو استرجاعه من إعدادات الحساب.
  4. اضغط اختبار الاتصال ثم سجّل الدخول.

عنوان Worker staging المتوقع (بعد النشر):

https://darb-gps-free-api.<account-subdomain>.workers.dev/api/v1
تنبيه: لا تدخل مفاتيح Supabase السرية أو Service Role أو كلمات المرور في عنوان API أو هذه الصفحة. يجب أن تبقى الأسرار على الخادم/Worker فقط.

حدود نسخة Cloudflare Free

  • الواجهة تستخدم طلب REST مجمّع للمواقع، ثم تحديثًا كل 60 ثانية عند عدم توفر Socket.IO.
  • تحديث GPS كل 5 ثوانٍ يستهلك نحو 17,280 طلبًا يوميًا لكل جهاز؛ حد Workers Free الحالي 100,000 طلب يوميًا للحساب.
  • تتطلب نسخة staging قاعدة Supabase staging منفصلة. لا تربط Worker التجريبي بقاعدة الإنتاج قبل اختبار الصلاحيات والتراجع.
